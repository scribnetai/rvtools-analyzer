What the analyzer reads

It parses the standard RVTools tabs — vInfo, vHost, vCluster, vDatastore, vDisk, vSnapshot, vCPU, vMemory, vNetwork, vTools — and tolerates both modern and legacy column names across RVTools versions. Missing a tab? That section simply degrades gracefully; vInfo alone still produces a useful briefing.

How the licensing math works

Broadcom licenses vSphere per physical core, with a minimum of 16 cores per CPU socket. A socket with fewer physical cores is still billed at 16 — the gap is phantom cores: licenses you pay for but can't use. For each host: license cores = sockets × max(cores per socket, 16). The analyzer rolls this up per cluster so you can see exactly where the waste lives and model consolidation scenarios.

⚠️ Indicative math, not a quote. Editions, bundles (VVF/VCF), and partner pricing change the dollars. Use this to frame the conversation — always validate against an official Broadcom quote.

Frequently asked questions

Is my RVTools data uploaded anywhere?

No. The file is read with the browser's FileReader API and parsed in memory by a vendored copy of SheetJS running in this page. There is no server, no analytics on file contents, and no network request carrying your data — you can open devtools' network tab and verify, or disconnect from the internet after the page loads.

Is anything stored in my browser?

No. The dataset lives only in the page's JavaScript memory for the session. Nothing goes to localStorage, IndexedDB, or cookies. Hit "Clear session data" (or just close the tab) and it's gone — the page holds no copy.

What RVTools versions are supported?

Any version that exports the standard Excel tabs. The parser matches both modern column names (e.g. Provisioned MiB) and legacy ones (e.g. Provisioned MB), so old and new exports both work.

Can I share the results with my team or the customer?

Yes — the Report tab generates a standalone HTML briefing you can download and email. It's fully self-contained (no external dependencies), and contains only the analysis, which you control.

Does it replace a real capacity assessment?

No — it's a first-pass briefing from a point-in-time inventory export. It can't see performance history, so right-sizing flags are "review candidates," not verdicts. Pair it with vROps / Aria Operations data for the full picture.
